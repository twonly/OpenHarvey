# Contributing

Open an issue for a reproducible bug or a focused feature proposal. For a pull request, explain the user-visible change and include relevant validation. Keep source citations, document versions, account ownership and actual file-save receipts intact.

Use Python 3.12 and Node.js 22. Run `python -m unittest discover -s tests -q` and `node --test tests/frontend.test.mjs`. Live model tests are separate from mocked tests; state which kind you ran.

Use fictional or licensed public documents in examples. Do not include customer contracts, personal information, credentials, private playbooks or execution logs from real users. Follow existing formatting and avoid unrelated rewrites.

Contributions are accepted under AGPL-3.0-only. By contributing, you confirm that you have permission to contribute the material under this license.
