# 合同资料使用手册

[English](materials-labs.md) · [在线说明书](https://openharvey.com/guide#materials) · [项目首页](../README.zh-CN.md)

合同资料把同一合同空间的主合同、报价单、技术附件等文件放在一起管理，供该空间内的对话按任务使用。它是 **Labs 实验功能，默认关闭，仅对自己的账号生效**。

本文对应支持「合同资料」的源码版本。托管站与自托管服务可能使用不同版本；请以设置 → Labs 是否出现「合同资料」为准。发布手册不代表所有服务已升级。

## 开启与第一轮使用

1. 在工作台打开 **设置 → Labs**，开启 **合同资料**。若有任务正在执行或派发，先等任务结束。
2. 打开一份合同空间及其中可继续对话的会话。主合同保持不变；开启后，该空间原有附件也可供同空间的其他对话使用。
3. 点击 **合同资料 → 管理**，或输入框旁的资料数量入口。通过 **添加资料** 选择多个文件，也可拖入文件。
4. 支持 DOCX、文字版 PDF、Markdown 和 TXT。普通账号单文件上限 20 MB；demo 按页面显示的额度和大小限制执行。
5. 查看每个文件的结果：**可用** 表示上传解析完成，**已存在** 表示当前空间已有相同内容；**失败** 可单独重试，不影响已成功的文件。文件按顺序处理，等待完成后再发送任务。
6. 输入具体任务，例如：“核对主合同和报价单的总金额、验收与付款期限；分别给出原文引用，列出不一致之处。”
7. 点击回答中的引用回到原文；展开 **引用来源** 查看该回答引用了哪些文件。需要文件时明确要求保存，再到产出物区预览或下载。

## 查找、移除和恢复

在管理窗口按文件名搜索，按格式筛选，点击文件名打开原文。主合同始终单独标识，不能从资料管理中移除。

其他资料可点 **移除**：文件不再进入后续任务的可用资料范围，已保存原件和旧回答中的引用仍保留。刚移除时可点 **撤销**；之后可将资料范围切换为 **已移除**，找到文件再点 **恢复**。移除资料不会抹去过去的对话内容。

重新上传当前资料中内容完全相同的文件会复用已有文件；文件名相同但内容不同仍作为另一份资料保存，不会自动覆盖旧版。需要限制采用哪份文件时，请在任务中明确说明，并移除不再使用的版本。

## 给助手明确的材料范围

空间中所有可用资料都可按需查找，无须逐次勾选。**可用不等于已阅读，引用来源也不代表全文审查覆盖率。**

| 任务 | 可以这样说 |
| --- | --- |
| 只看主合同 | “本次只看主合同，忽略报价单，说明验收后多久付清款项，并引用原文。” |
| 比较文件 | “对比主合同与技术附件的交付范围，分别列出约定和不一致点。” |
| 限定参考文件 | “以主合同为准，仅用这份报价单比较价格，不把报价单当作已签合同约定。” |
| 保存成果 | “把上述差异保存成一份表格文件，保留文件名和原文引用。” |

合同资料保存项目原文；个人记忆保存你的工作偏好；Skills 保存任务方法；风险库保存审查标准。合同金额、主体、期限等事实应以本次材料为依据。

## 关闭后会怎样？

回到 **设置 → Labs** 关闭合同资料后，界面恢复原附件入口，已有资料与历史引用保留，再次开启仍可管理。默认材料范围恢复为原有运行方式：本地会话使用主合同及该会话附件，云端合同空间沿用原有的空间材料范围。关闭开关不是删除资料，也不是撤回已发送给模型的上下文。

## 常见问题

- **为什么现在不能上传、移除或关闭？** 空间内有运行或正在派发的任务时，系统保持其材料范围稳定。等任务结束后再操作；归档、已删除的会话需恢复后才能继续使用。
- **扫描 PDF 能直接使用吗？** 本功能沿用现有文档解析能力，不新增 OCR。无法提取文字时请提供可读取的文字版文件。
- **为什么刷新后不能直接重试刚才失败的文件？** 浏览器不会永久保存待上传文件；刷新后重新选择即可，成功上传的资料已保留。
- **是否是跨合同知识库？** 当前按合同空间管理，不提供跨空间全局 Vault、文件夹、自动分类或 Review Tables。
- **是否对其他账号共享？** 不会。Labs 开关、空间访问和资料管理继续按账号隔离。
